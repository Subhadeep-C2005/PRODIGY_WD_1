# Prodigy InfoTech Landing Page - Task 01

A fully responsive landing page built for Prodigy InfoTech's virtual internships program[cite: 3]. This fan-made demo site was developed as Task 01 for the Web Development Internship[cite: 3]. 

## 🚀 Live Demo
**View the live deployed site here:** [https://prodigy-wd-1-sand.vercel.app](https://prodigy-wd-1-sand.vercel.app) *(Deployed via Vercel as shown in image_1d8ac0.png)*

## ✨ Features
*   **Interactive Navigation:** A fixed navigation bar that dynamically changes its background and shadow styling when the user scrolls down the page[cite: 2, 4].
*   **Mobile Responsiveness:** A fully functional hamburger menu toggle for smaller screens, allowing users to open and close the navigation links seamlessly[cite: 2, 4].
*   **Modern UI/UX:** Clean, responsive design utilizing CSS Grid and Flexbox to display the internship tracks and informational cards[cite: 4].
*   **Custom Styling:** Implements CSS variables for a consistent color theme (Navy, Blue, Ice, Gray) and utilizes Google Fonts (Sora and Inter) for professional typography[cite: 3, 4].
*   **Structured Content Layout:** Includes clearly defined, smoothly scrolling sections such as "Tracks," "How it works," "Why us," and a "Contact" form[cite: 3, 4].

## 🛠️ Technologies Used
*   **HTML5:** For semantic page structuring and content organization[cite: 3].
*   **CSS3:** For styling, custom color variables, smooth hover transitions, and responsive media queries targeting screens under 900px and 768px[cite: 4].
*   **JavaScript (Vanilla):** For DOM manipulation, specifically handling the window scroll events and toggling the mobile menu active states[cite: 2].
*   **Vercel:** For instant production deployment (referenced in image_1d8ac0.png).

## 📂 Project Structure
*   `index.html`: Contains the core HTML structure and content[cite: 3].
*   `style.css`: Contains all styling, animations, and responsive design rules[cite: 4].
*   `app.js`: Contains the JavaScript logic for the scrolling navbar and mobile menu[cite: 2].
