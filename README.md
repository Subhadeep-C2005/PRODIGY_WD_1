# Prodigy InfoTech Landing Page - Task 01

A fully responsive landing page built for Prodigy InfoTech's virtual internships program. This fan-made demo site was developed as Task 01 for the Web Development Internship. 

## 🚀 Live Demo
**View the live deployed site here:** [https://prodigy-wd-1-sand.vercel.app](https://prodigy-wd-1-sand.vercel.app) *(Deployed via Vercel)*

## ✨ Features
*   **Interactive Navigation:** A fixed navigation bar that dynamically changes its background and shadow styling when the user scrolls down the page.
*   **Mobile Responsiveness:** A fully functional hamburger menu toggle for smaller screens, allowing users to open and close the navigation links seamlessly.
*   **Modern UI/UX:** Clean, responsive design utilizing CSS Grid and Flexbox to display the internship tracks and informational cards.
*   **Custom Styling:** Implements CSS variables for a consistent color theme (Navy, Blue, Ice, Gray) and utilizes Google Fonts (Sora and Inter) for professional typography.
*   **Structured Content Layout:** Includes clearly defined, smoothly scrolling sections such as "Tracks," "How it works," "Why us," and a "Contact" form.

## 🛠️ Technologies Used
*   **HTML5:** For semantic page structuring and content organization.
*   **CSS3:** For styling, custom color variables, smooth hover transitions, and responsive media queries targeting screens under 900px and 768px.
*   **JavaScript (Vanilla):** For DOM manipulation, specifically handling the window scroll events and toggling the mobile menu active states.
*   **Vercel:** For instant production deployment.

## 📂 Project Structure
*   `index.html`: Contains the core HTML structure and content.
*   `style.css`: Contains all styling, animations, and responsive design rules.
*   `app.js`: Contains the JavaScript logic for the scrolling navbar and mobile menu.
